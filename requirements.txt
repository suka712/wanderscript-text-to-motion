# Pinned to the exact versions proven working on the 4090 (conda env `afford`,
# python 3.8.20) across every verify script in this repo as of 2026-08-09. This is
# NOT the same as T2M-GPT's own upstream environment.yml (torch 1.8.1 / cuda10.1) --
# that combo predates and is incompatible with Ampere/Ada-generation cards (3090/4090).
# When setting up a new machine, match THIS list, not T2M-GPT's.
#
# Install order matters for the two git-sourced packages below (torch must exist
# first). Suggested sequence:
#   conda create -n wander python=3.8.20 -y && conda activate wander
#   pip install torch==1.12.0+cu113 torchvision==0.13.0+cu113 torchaudio==0.12.0 \
#     --extra-index-url https://download.pytorch.org/whl/cu113
#   pip install -r requirements.txt
#
# cu113 wheels work on newer drivers via CUDA's minor-version compatibility; if the
# target machine's driver is too old for cu113, that will surface as a torch.cuda
# import/availability failure -- check `nvidia-smi` driver version first.
